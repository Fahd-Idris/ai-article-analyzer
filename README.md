# AI Article Analyzer

## Description

A Python application that analyzes text using Hugging Face Transformers.

This project was built after completing Chapter 2 of the Hugging Face course and was created to practice working with pretrained models and tokenizers.

## Features

- Analyzes user-provided text
- Uses a pretrained Hugging Face model
- Uses a tokenizer to prepare text for the model
- Displays the model's output
- Provides an interpretation of the result

## Technologies

- Python
- Hugging Face Transformers
- Google Colab

## How to Run

1. Install the required libraries.
2. Run the Python program.
3. Enter the text when prompted.
4. Follow the instructions displayed by the program.

- How tokenization works
- How to load a pretrained model
- How to pass tokenized text to a model
- How to interpret model outputs
- How to build an application around a pretrained transformer model
